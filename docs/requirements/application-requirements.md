# アプリケーション要件定義

## 1. アプリケーション概要

本アプリケーションは、ゲーム用の武器振りモーションを制作する個人開発者・小規模チーム向けに、武器を振る 2D 動画から人型 3D アニメーションを生成し、さらに武器の物理的制約とキャラクター属性に応じて自動補正・強調する制作支援システムである。

README に記載された研究課題では、既存の AI モーションキャプチャが入力動画の動きを忠実に変換する一方で、重い武器を扱う際の慣性、重心移動、タメとツメ、ヒットストップ、キャラクター能力差を十分に反映できないことが問題として示されている。また、個人制作では FBX などの 3D モーション素材を事前に用意すること自体が難しい。本アプリケーションはその問題を解決するため、2D 動画から人型の 3D 骨格モーションを推定し、物理的な説得力とゲームらしい誇張を付与した補正済みモーションを生成する。

## 2. 想定ユーザー

- 3D アクションゲームを制作する個人開発者
- 専門アニメーターを常時確保できない小規模ゲームチーム
- スマートフォン等で撮影した 2D 動画からゲーム用 3D モーションを作りたい制作者
- 武器種やキャラクター設定ごとの差分モーションを効率的に作成したい開発者

## 3. 解決する課題

### 3.1 3D モーション素材を用意する難しさ

個人制作や小規模開発では、FBX などの人型 3D モーションを自力で作成したり、品質の高いモーションキャプチャ環境を用意したりすることが難しい。アプリケーションは、ユーザーが撮影した武器振りの 2D 動画を入力として受け取り、人体姿勢推定、時系列補間、3D 骨格への変換を行うことで、補正処理の元になる人型 3D アニメーションを生成する。

### 3.2 物理的説得力の不足

軽い棒を振った動画から生成されたモーションは、ゲーム内の大剣、斧、ハンマーなどの重い武器にそのまま適用すると重量感が不足する。アプリケーションは、武器の質量、長さ、重心位置、慣性モーメントを考慮し、振り始め、振り抜き、反動、姿勢崩れを補正する。

### 3.3 ゲームアニメーションとしての見栄え不足

現実の動きをそのまま再現するだけでは、ゲームに必要なキレや爽快感が出にくい。アプリケーションは、タメ、加速、フォロースルー、ヒットストップ、ポーズの誇張を調整し、入力モーションをゲーム向けに強調する。

### 3.4 キャラクター属性の反映不足

筋力、敏捷性、体幹、熟練度などのキャラクター設定により、同じ武器でも振り方や反動の抑え方は変化する。アプリケーションはキャラクター属性をパラメータとして受け取り、モーションタイミング、姿勢安定性、反動量、回復フレームへ反映する。

## 4. 対象データ

### 4.1 入力

- 武器を振る人物を撮影した 2D 動画ファイル
- 動画メタデータ
  - フレームレート
  - 解像度
  - 撮影方向
  - 開始フレームと終了フレーム
- 将来的な補助入力として FBX、BVH、glTF
- 武器パラメータ
  - 武器種
  - 質量
  - 長さ
  - 重心位置
  - 打撃点
- キャラクター属性
  - 筋力
  - 敏捷性
  - 体幹
  - 熟練度
  - 身長または体格スケール
- 補正プリセット
  - リアル寄り
  - アクションゲーム寄り
  - アニメ調
  - ボスキャラクター向け

### 4.2 出力

- 推定された人型 3D 骨格モーション
- 補正済み FBX モーション
- 将来的な glTF、BVH 出力
- 入力動画、推定 3D、補正後 3D の比較用プレビュー
- 補正前後の差分レポート
- ジョブ実行ログ
- 物理・誇張パラメータの保存済みプリセット

## 5. 主要機能

### 5.1 プロジェクト管理

ユーザーはモーション補正作業をプロジェクト単位で管理できる。プロジェクトには入力動画、推定 3D モーション、武器設定、キャラクター設定、補正プリセット、生成履歴を紐付ける。

### 5.2 動画アップロード

ユーザーは武器を振る 2D 動画ファイルをアップロードし、アプリケーション上で動画情報を確認できる。アップロード時にはファイル形式、サイズ、長さ、解像度、フレームレートを検証する。

### 5.3 2D 動画から 3D モーションへの変換

アプリケーションは入力動画から人体の 2D 姿勢を推定し、時系列補間とノイズ除去を行ったうえで、人型 3D 骨格アニメーションへ変換する。変換結果は補正前モーションとして保存し、後続の武器・キャラクター補正の入力にする。

### 5.4 武器パラメータ設定

ユーザーは武器種、質量、長さ、重心位置を入力できる。プリセットから選択することも、数値を直接編集することもできる。

### 5.5 キャラクター属性設定

ユーザーはキャラクターの筋力、敏捷性、体幹、熟練度を設定できる。これらの値は、初動の遅さ、最大加速度、反動制御、回復動作に影響する。

### 5.6 補正・強調ジョブの実行

アプリケーションは入力動画、推定 3D モーション、武器パラメータ、キャラクター属性、補正プリセットをもとに worker へジョブを投入する。ジョブは非同期に実行し、進捗、失敗理由、成果物 URL を追跡する。

### 5.7 補正結果プレビュー

ユーザーは入力動画、推定 3D モーション、補正後モーションを比較できる。Web 画面では動画再生と 3D ビューアを同期し、再生、停止、フレーム送り、再生速度変更、補正前後の切り替えを行える。

### 5.8 パラメータ調整と再生成

ユーザーは補正結果を確認しながら、武器・キャラクター・誇張パラメータを調整して再生成できる。同一入力に対する複数バージョンを保存し、比較できる。

### 5.9 エクスポート

補正済みモーションを FBX としてダウンロードできる。将来的には Unity、Unreal Engine、Blender 向けの出力プリセットを用意する。

## 6. 画面要件

### 6.1 ダッシュボード

- 最近のプロジェクト一覧を表示する
- ジョブ実行中、完了、失敗を確認できる
- 新規プロジェクトを作成できる

### 6.2 プロジェクト詳細

- 入力動画、推定 3D モーション、武器設定、キャラクター設定、生成履歴を表示する
- 3D 生成・補正ジョブを開始できる
- 補正済みバージョンを選択できる

### 6.3 モーション調整画面

- 入力動画と 3D プレビューを表示する
- 補正前後を切り替えられる
- 武器パラメータとキャラクター属性を編集できる
- 補正プリセットを選択できる
- ジョブ進捗と失敗理由を確認できる

### 6.4 エクスポート画面

- 出力形式と対象バージョンを選択できる
- ダウンロードリンクを発行する
- 生成済み成果物の履歴を表示する

## 7. 非機能要件

### 7.1 性能

- Web 画面は動画解析や 3D 変換を直接行わず、アップロード後の重い解析は worker に委譲する
- ジョブは非同期実行し、Web/API のリクエスト応答を長時間ブロックしない
- プレビュー用データは必要に応じて軽量形式へ変換する

### 7.2 信頼性

- ジョブ状態を永続化し、処理中断後も進捗と失敗理由を確認できる
- 入力動画、推定 3D モーション、補正パラメータ、出力ファイルの対応関係を追跡できる
- 失敗時は再実行できる

### 7.3 セキュリティ

- アップロード動画の拡張子、MIME、サイズ、再生時間を検証する
- ユーザーごとにプロジェクトと成果物へのアクセスを制御する
- 署名付き URL などを用い、成果物の公開範囲を制限する

### 7.4 保守性

- Web、API、worker の責務を分離する
- API 契約型は共有パッケージで管理する
- モーション補正ロジックは worker 内でモジュール化し、将来のアルゴリズム差し替えを容易にする

## 8. 初期リリース範囲

初期リリースでは、研究検証とプロトタイプ開発を優先し、以下を対象とする。

- ユーザー認証は簡易的な開発用認証、または後続実装とする
- 入力形式はスマートフォン等で撮影した 2D 動画を主対象とする
- 1 つの入力動画から人型 3D 骨格モーションを生成する
- 生成された 3D モーションに対し、武器・キャラクター設定を指定して 3D 生成・補正ジョブを実行する
- 補正済み FBX を生成し、入力動画、推定 3D、補正後 3D の比較プレビューを行う
- ジョブ履歴と補正パラメータを保存する

## 9. 将来拡張

- 複数カメラ動画や高精度姿勢推定モデルへの対応
- Unity、Unreal Engine への直接連携
- 複数武器種に特化した補正モデル
- 手付け調整用のキーフレーム編集
- チーム共有、レビューコメント、承認フロー
- 学習済みモデルによるモーション品質評価
