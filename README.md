# character-fbx-director

## 研究タイトル
物理的制約とキャラクター属性を考慮したゲーム用武器振りモーションの自動補正・強調システムの開発
Development of an Automatic Correction and Exaggeration System for Game Weapon Swing Motions Considering Physical Constraints and Character Attributes

## 背景
近年、ゲームエンジンの普及により、個人や少人数でのインディーゲーム制作が盛んに行われている。3Dアクションゲームにおいて、プレイヤーの没入感や操作の爽快感を高めるためには、キャラクターの「魅力的で説得力のあるモーション」が不可欠である。
しかし、このような高品質なモーションを制作することは、専門的な技術と経験を要する。プロの現場では、モーションキャプチャのデータをベースに、専門のアニメーターやモーションディレクター（監修者）が手作業でタイミングの緩急（タメとツメ）やポーズの誇張を調整することで、ゲームとしての見栄えを担保している。一方で、監修者が存在しない個人開発においては、アニメーションの原則に基づく高度な調整を行うことは極めて困難であり、開発者にとって大きな障壁となっている。
現状、個人開発者は自身の動作をスマートフォン等で撮影し、それを参考に手付けでアニメーションを作成するか、動画から姿勢を推定するツールを利用している。しかし、素人が演じた動きには「重量感」や「キレ」が欠けており、そのままではゲーム内のダイナミックなアクションとして成立しないという問題が存在している。

## 課題
上記の問題を解決する手段として、近年、動画から自動で3Dモーション（FBX等）を生成するAIモーションキャプチャシステム（PlaskやDeepMotionなど）が登場している。しかし、これらの既存システムをゲームのアニメーション制作に適用するうえで、以下の2つの大きな課題が存在する。
① 現実の物理法則への過剰な忠実性と、力学モデルの不在
既存のシステムは、動画内の人物の動きを3D空間の骨格データへ「忠実に」変換することに特化している。そのため、入力者が現実世界で「軽い棒」を振っている動画を用いた場合、出力されるモーションも「軽い棒を振っている動き」にしかならない。
ゲーム内でキャラクターが大剣や巨大なハンマーといった重い武器を扱う場合、剛体力学に基づく慣性モーメントの働きや、振り抜いた後の重心の移動などが必要となる。既存システムには、持っている武器の質量や形状、重心といった「力学的なパラメータ」をモーションに反映させる仕組みが存在せず、結果として重量感の欠如した説得力のないアニメーションが生成されてしまう。
② ゲーム特有のアニメーション的誇張とキャラクター属性の反映困難性
魅力的なゲームアニメーションには、現実の動きをそのままトレースするのではなく、人体の解剖学的な可動域を意図的に拡張したポージングや、非線形な時間軸の操作（ヒットストップや瞬間的な加速）といった「誇張（Exaggeration）」が求められる。
また、キャラクターの「筋力」や「運動神経」といった設定によって、武器を振る際の初動の速さや反動の抑え込み方は大きく異なる。しかし、現状のシステムは入力された動画の時系列データをそのまま等速で出力するのみであり、キャラクター固有の属性数値を入力として、動きの軌道やタイミングを自動で最適化・補正する機能は備わっていない。
結果として、開発者は出力されたモーションデータに対し、多大な時間と労力をかけて手動でのクリーナップ作業（キーフレームの打ち直しやカーブの調整）を強いられており、真の意味での制作コスト削減には至っていない。
